Ninedogs 개인정보처리방침

시행일: 2026년 7월 26일

Ninedogs(이하 "앱")는 구독 서비스를 관리하는 개인용 앱입니다. 이 문서는 앱이 어떤 정보를 다루고, 어떻게 쓰이며, 누구와 공유되는지(공유되지 않는지) 설명합니다.

1. 수집하는 정보

정보내용저장 위치
구독 정보 서비스 이름, 요금, 결제 주기, 시작일·해지일, 결제 수단 메모 기기 내부. 가족 공유를 켠 경우 Firebase(Firestore)에도 저장
계정 아이디·비밀번호(선택 기능) 사용자가 직접 입력한 각 서비스의 로그인 정보 기기에서 암호화(AES-256-GCM) 후 저장. 가족 공유를 켠 경우 암호문만 Firestore에 저장 — 서버는 평문을 알 수 없음
앱 사용 기록(선택 기능, 기본 꺼짐) 다른 앱을 마지막으로 연 시각. Android "사용 정보 접근" 권한을 사용자가 직접 켜야 동작 기기에서만 처리. 어디로도 전송되지 않음
익명 식별자 Firebase 익명 인증이 발급하는 임의의 ID. 실명, 이메일, 전화번호를 수집하지 않음 Firebase Authentication
알림 예약 정보 결제 예정일 알림을 위한 로컬 알림 예약 기기 내부. 서버로 전송되지 않음

2. 가족 공유(Firebase 동기화)는 선택 사항입니다

앱을 설치한 것만으로는 누구와도 데이터가 연결되지 않습니다. 설정 화면에서 직접 "가족 연결"을 켜고 초대 코드를 주고받아야만 구독 정보가 Firebase를 통해 같은 가족 구성원과 공유됩니다. 켜지 않으면 모든 정보는 기기에만 남습니다.

3. 제3자 제공

수집한 정보를 광고, 마케팅, 분석 목적으로 제3자에게 제공하거나 판매하지 않습니다. 앱에는 광고 SDK, 분석(애널리틱스) SDK가 포함돼 있지 않습니다.

가족 공유 기능을 위해 Google Firebase(Firebase Authentication, Cloud Firestore)를 인프라로 사용합니다. Firebase의 데이터 처리는 Firebase 개인정보처리방침을 따릅니다.

4. 보안

계정 아이디·비밀번호는 사용자가 정한 마스터 암호로부터 PBKDF2-HMAC-SHA256 (12만 회 반복)으로 키를 만들어 AES-256-GCM으로 암호화합니다. 이 키는 기기 메모리에만 존재하며 저장되지 않습니다. 마스터 암호를 잊으면 저장된 계정 정보는 복구할 수 없습니다.

5. 데이터 삭제

설정 화면에서 언제든 다음을 할 수 있습니다.

  • 가족 공유 연결 해제(연결 해제 시 기기에 데이터가 남고 서버 쪽 접근은 끊김)
  • 앱 데이터 전체 초기화
  • 앱 삭제 시 기기에 저장된 모든 정보(구독 내역, 암호화된 계정 정보, 알림 예약)가 함께 삭제됨

6. 만 14세 미만 이용자

이 앱은 구독 결제 관리를 위한 일반용 앱으로, 만 14세 미만 아동을 대상으로 하지 않으며 아동으로부터 개인정보를 의도적으로 수집하지 않습니다.
